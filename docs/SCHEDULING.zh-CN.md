# 每日调度与安全补查

日期与时间均为 UTC+8。微博、NodeSeek 和虎牙每天各自独立选择一个 **08:00（含）–12:00（不含）** 的首签分钟。NodeSeek 可在这个范围内选择更窄的时段。随机结果由日期、平台和私有加密密钥生成，刷新页面、重启 Worker 不会重新抽签。

共享 `* * * * *` Cron 只检查计划是否到期。平台在访问上游前保存本次尝试和下次补查时间，间隔随机 **45–75 分钟**，向上取整到分钟。安全的未完成任务中午后仍可补查，持续到当天结束；补查不跨入次日，次日重新采用上午首签计划。Cloudflare 可能延迟触发，因此面板显示的是计划到期时间，并非精确送达保证。

| 平台 | 补查方式 | 完成与暂停 |
| --- | --- | --- |
| 微博 | 登录检测 GET 暂时网络失败后重试；跳过当天已完成的超话。 | 登录失效或验证会停止。签到 POST 待确认或结果不明时，当天不自动重复提交，核对后可手动恢复；次日登录有效时重新开始每日签到。手动停止会暂停当天后续计划。 |
| NodeSeek | 网络、服务器、浏览器及限流等暂时故障可补查。写入结果不明时，先读账单；证据不足时只继续读，不重复提交。 | 当天确认成功后不再签到。登录、验证和配置错误需人工处理。 |
| 虎牙 | 空背包、送出前读取失败后重新检测；赠送时读取当前全部免费虎粮。 | 每天最多成功赠送一次。待确认订单、回执不明会跨日暂停，须明确核对解除。没有付费兜底。 |

平台开关开启且凭证、配置齐全才执行；首次安装默认关闭。手动与自动操作共用当日去重，手动执行也不能绕过虎牙待核对订单锁。面板显示下一次计划时间或暂停提示，当天成功后显示次日上午的计划。

升级保留凭证、历史、平台开关和房间配置。旧虎牙失败或空背包记录会从实际尝试时间生成补查计划；旧固定时间字段仅为 API 兼容保留，不再控制自动执行。NodeSeek 已保存的有效上午时段继续使用，超出 08:00–12:00 的旧时段回退到完整上午时段。
